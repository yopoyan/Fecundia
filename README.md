Fecundia is a desktop workspace for product growth. Draft content for supported channels, review it before publishing, and track website traffic and Stripe revenue in one workspace.

Fecundia 是面向产品团队的 AI 增长工作台。你可以在桌面端生成和审核各渠道的内容草稿、发布内容，并查看网站流量和 Stripe 收入。

## Download for Windows · 下载 Windows 客户端

Open the [latest release](https://github.com/yopoyan/Fecundia/releases/latest) and download the `x64-Setup.exe` installer from **Assets**. This public repository hosts the product overview, artwork, installers and release notes.

打开[最新版本](https://github.com/yopoyan/Fecundia/releases/latest)，在 **Assets** 中下载以 `x64-Setup.exe` 结尾的安装包。此公开仓库用于产品介绍和版本发布。
